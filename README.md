# LEGAL

各アプリの利用規約・プライバシーポリシー・サポートページを 1 つに集約したリポジトリ。
GitHub Pages で公開し、App Store Connect の各 URL から参照する。

公開URL: https://jinkato2020.github.io/LEGAL/

## 構成（アプリごとにサブフォルダ）

```
LEGAL/
├── index.html          … 一覧ランディング
├── .nojekyll           … Pages の Jekyll 処理を無効化
├── crane/              … クレーン・デリック運転士 試験対策
│   ├── privacy.html    … プライバシーポリシー
│   └── support.html    … サポート・お問い合わせ
└── cae/                … CAE試験対策
    ├── privacy.html    … プライバシーポリシー
    ├── terms.html      … 利用規約
    └── support.html    … サポート・お問い合わせ
```
